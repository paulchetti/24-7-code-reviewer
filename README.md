# The 24/7 Intelligent Code Reviewer
**Code Kitchen Track 01 Hackathon Project**

This repository contains the complete codebase for **"The 24/7 Intelligent Code Reviewer"**, an autonomous, multi-language code review and developer growth tracking platform built exclusively on Google Cloud Platform (GCP) native services: **Vertex AI (Gemini + text-embedding-004)**, **Cloud Firestore**, **Google Cloud Identity Platform / Firebase Auth**, and **Cloud Run**.

The full project code is located in [`code-reviewer/`](./code-reviewer/):

- **Backend**: [`code-reviewer/backend/`](./code-reviewer/backend/) — FastAPI, Vertex AI, text-embedding-004, Cloud Firestore, Dockerfile
- **Frontend**: [`code-reviewer/frontend/`](./code-reviewer/frontend/) — React, Tailwind CSS, Monaco Editor, Growth Charts
- **Scripts**: [`code-reviewer/scripts/`](./code-reviewer/scripts/) — `deploy_gcp.sh` and `seed_rules.csv`

For comprehensive documentation, architecture diagrams, setup instructions, and deployment guides, please see:
👉 **[code-reviewer/README.md](./code-reviewer/README.md)**
